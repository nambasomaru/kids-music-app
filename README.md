# きいてね! おんがくプレーヤー

子ども向けのシンプルなMP3プレーヤーアプリです。
フレームワークなしの HTML/CSS/JavaScript のみで作られているので、
古いスマホのブラウザでも動きやすく、PCだけで開発・テストできます。

## 画面と操作

- 画面いっぱいに 6×4 = 24個のボタン
- 左上から23個は曲ボタン（1曲ずつ割り当て）→ タップでその曲を再生
- 右下の赤いボタンがストップ/電源ボタン
  - 再生中に押す → 停止
  - 何も再生していない状態で押す → アプリがオフ状態になる（画面が暗くなる）
  - 暗い画面をタップすると再びボタン画面に戻ります
    （※ブラウザの仕組み上、Webアプリが自分自身を完全に終了させることは
      セキュリティ上できないため、"暗い画面＝オフ"として表現しています。
      端末によっては実際にタブが閉じることもあります。）

## フォルダ構成

```
kids-music-app/
├─ index.html      ... 画面のベース
├─ style.css        ... 見た目(色・レイアウト)
├─ app.js           ... 曲の設定と再生ロジック
├─ manifest.json    ... ホーム画面アイコン用の設定
├─ sw.js            ... オフラインでも使うための仕組み
├─ icons/           ... アプリアイコン画像
└─ songs/           ... ここに mp3 を入れる
```

## 1. 曲を入れる

`songs` フォルダに mp3 ファイルを入れて、`app.js` の先頭にある
`SONGS` の配列を書き換えてください。

```js
var SONGS = [
  { title: "きらきら星", file: "songs/kirakira.mp3" },
  { title: "ぞうさん",   file: "songs/zousan.mp3" },
  ...
];
```

23曲ぶん、上から順にボタン1〜23に割り当てられます。

## 2. PCでテストする

ブラウザは「file://」で開くと manifest やオフライン機能が正しく
動かないことがあるので、簡易サーバーを使うのがおすすめです。

Python が入っていれば、フォルダの中で:

```
python3 -m http.server 8000
```

を実行し、ブラウザで `http://localhost:8000/` を開けば確認できます。
（Node.jsがあれば `npx serve` などでも構いません）

## 3. スマホにアイコンとして設置する

スマホの標準ブラウザから「ホーム画面に追加」するには、
アプリが https（または同じWi-Fi内のローカルサーバー）で
開ける状態になっている必要があります。主な方法:

- **GitHub Pages / Netlify などに公開**（一番手軽で確実）
  このフォルダをそのままアップロードするだけで https で公開できます。
- **自宅Wi-Fi内で公開**
  PCで `python3 -m http.server 8000` を実行し、
  スマホから `http://(PCのIPアドレス):8000/` にアクセス。

開けたら:

- **Android(Chrome)**: メニュー →「ホーム画面に追加」
- **iPhone(Safari)**: 共有ボタン →「ホーム画面に追加」

これでホーム画面にアイコンが作られ、タップするとブラウザのアドレスバー
などが無いアプリのような画面で起動します。

## 動作環境の目安

- Android 5以降のChrome、iOS 10以降のSafari程度であれば
  基本的な再生・停止は動作する想定です。
- 非常に古い端末では `Audio` の同時再生数やファイル形式に制限が
  ある場合があります。動作が不安定な場合は mp3 のビットレートを
  下げる（128kbps程度）と安定しやすいです。

## カスタマイズ

- ボタンの色: `style.css` の `.c0`〜`.c5`
- アイコン画像: `icons/icon-192.png` / `icons/icon-512.png`
  を好きな画像に差し替え可能（サイズは同じにしてください）
